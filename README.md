# 文件对照台
浏览器本地SHA-256文件清单和版本核对。纯前端、无依赖、无上传接口、无API费用。
打开HTTPS部署或localhost网页；node build.cjs构建单文件；node --test tests/core.test.cjs验证。
选择两版完整文件集或导入自家JSON清单。按名称（区分大小写）、大小、SHA-256分成未变/修改/新增/移除；唯一同内容新增移除对仅提示可能改名。
每版100文件、每文件25MiB、总100MiB；JSON128KiB；非目录工具，跨文件夹重名须先区分。主动保存后只恢复快照，不自动保存后续修改。
不证明作者、版权、时间或相似度。导出包含文件名，分享前自行检查。
